# platform/web/

Web and WebXR adapter for Me-google xrOS.

## Purpose

This module will map `core/` spatial models to TypeScript, React, WebXR reference spaces, WebCrypto, and browser storage.

## Public API surface

Planned surfaces:

- TypeScript adapters over `core/models`;
- React spatial UI components;
- WebXR anchors/reference-space placement;
- WebCrypto and IndexedDB adapters for encrypted local/session data.

## Tests

No web app scaffold exists yet. When scaffolded, document and run the web unit test command from this directory.
